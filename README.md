**Nebula Firewall Atlas** is a *standalone legendary* defensive terminal tool. No dependencies, single-file, offline, advanced CLI.

## Install (10s)
```bash
git clone https://github.com/hz8n/void-firewall.git
cd void-firewall
chmod +x void-firewall.py
./void-firewall.py --help
./void-firewall.py --target 127.0.0.1 --output report.json
```
